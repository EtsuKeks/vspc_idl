# Chains (run scenarios)

Generated by `./stand.sh gen` from `CHAINS` in `synth/model.py`. A chain is a sequence of loads run on one stand root per version; every load = one JVM (sources of the load -> product run at the fake time -> export). Run: `./stand.sh run <chain> [--only 30|40] [--upto <load>]`, results in `target/runs/<chain>_<time>/summary.txt`.
